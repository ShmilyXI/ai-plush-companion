# ESP32-S3 摄像头桌面外壳

本目录包含 ESP32-S3 EVB + OV3660、1.54 英寸 ST7789 屏幕、35 × 25 mm 扬声器、15 × 15 mm I²S 麦克风和 MAX98357A 功放的参数化外壳模型。

装配后的目标外形为 `105 × 70 × 32 mm`。前壳深度为 `29.6 mm`，后盖外板厚 `2.4 mm`；后盖定位舌伸入前壳，不增加整机深度。

## 生成环境

所有依赖安装在项目局部虚拟环境中：

```bash
cd enclosure
/opt/homebrew/bin/python3.11 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m pytest tests -v
.venv/bin/python -m src.export_all
```

生成文件位于 `enclosure/output/`。该目录中的 CAD 文件可随参数重新生成，因此不提交到 Git。

## 输出文件

| 文件 | 用途 |
| --- | --- |
| `front_shell.stl/.step` | 一体式前壳、面板、模块支撑和声学隔离结构 |
| `rear_cover.stl/.step` | M2 螺钉后盖和定位舌 |
| `button_caps.stl/.step` | BOOT、RESET 两个凹入式按键帽 |
| `pcb_retainer.stl/.step` | ESP32 开发板可拆卸固定条 |
| `fit_display.stl/.step` | 屏幕 PCB 间隙试配条 |
| `fit_usb.stl/.step` | 双 USB-C 孔位和插头间隙试配片 |
| `fit_buttons.stl/.step` | BOOT/RESET 孔位和滑动间隙试配片 |
| `manifest.json` | 每个 STL 的尺寸、体积和封闭性验证结果 |

## 必须先打印试配片

USB-C 与按键位置来自带尺子的照片估算，而不是游标卡尺坐标。不要直接把完整前壳作为第一次打印。

先打印：

1. `fit_display.stl`
2. `fit_usb.stl`
3. `fit_buttons.stl`
4. `button_caps.stl`

试配片使用凸点标记三个区域：一个点代表第一档，两个点代表第二档，三个点代表第三档。

| 试配结果 | 完整外壳导出前修改的参数 |
| --- | --- |
| 屏幕第一、第二或第三档能轻压装入 | 将 `display_total_clearance` 设为 `0.2`、`0.4` 或 `0.6` |
| USB 第一、第二或第三档同时对准两个接口 | 给两个 `usb_edge_centres` 同时加 `-0.4`、`0.0` 或 `+0.4` |
| USB 插头可完全插入且缝隙不过大 | 将 `usb_plug_clearance` 设为该档的 `0.6`、`0.8` 或 `1.0` |
| 按键第一、第二或第三档同时对准两个开关 | 给两个 `button_edge_centres` 同时加 `-0.4`、`0.0` 或 `+0.4` |
| 按键帽滑动顺畅且晃动较小 | 将 `button_slide_clearance` 设为 `0.2`、`0.3` 或 `0.4` |

所有修正只改 `src/parameters.py` 中对应数值。修改后重新运行全部测试并执行：

```bash
.venv/bin/python -m pytest tests -v
.venv/bin/python -m src.export_all
```

## 推荐打印参数

- 材料：PLA
- 喷嘴：0.4 mm
- 层高：0.2 mm
- 壁数：3
- 顶层/底层：4
- 填充：15–20%
- 支撑：关闭
- 首层象脚补偿：建议 0.15–0.25 mm

摆放方向：

- 前壳：可见正面贴打印平台，背面开口向上。
- 后盖：外侧大平面贴打印平台，定位舌向上。
- 按键帽：直径 6 mm 的圆头平面贴打印平台。
- PCB 固定条与试配片：最大平面贴打印平台。

模型按普通 PLA/FDM 的无支撑打印设计。切片后仍应检查是否出现孤立首层、异常桥接或自动生成的强制支撑。

## 安装材料

- M2 × 8 mm 自攻方式螺钉 4 颗
- 扬声器周边约 1 mm 厚闭孔泡棉
- 麦克风周边软泡棉或薄硅胶垫
- 短焊线和热缩管
- 可选：后盖外侧粘贴式防滑脚垫

## 装配顺序

1. 打印并确认屏幕、USB-C 和按键试配片。
2. 按试配结果修正参数，重新导出完整零件。
3. 把屏幕从后方装入左侧定位框，确认可视区域无遮挡。
4. 把 ESP32-S3 板滑入上下导轨，使 OV3660 对准镜头孔，并装上 PCB 固定条。
5. 装入两个按键帽，确认能分别触发 BOOT 和 RESET 且不会卡住。
6. 在麦克风仓加入隔振泡棉并安装麦克风，拾音孔对准 2 mm 声道。
7. 在扬声器周边铺 1 mm 泡棉密封条，装入扬声器；扬声器仓与麦克风仓不能形成直通缝隙。
8. 安装 MAX98357A，保持绿色接线端子和焊点朝后可维护；完成短焊线并通过扎线点释放拉力。
9. 合盖前测试屏幕、摄像头、麦克风、扬声器、两个 USB-C、BOOT 和 RESET。
10. 整理导线，确认后盖不会压线，再用四颗 M2 × 8 mm 螺钉均匀锁紧。

M2 螺钉直接在 PLA 的 1.6 mm 导孔中攻牙。第一次锁紧应低速、轻扭矩，感觉阻力突然增大时立即停止，避免柱位开裂。

## 首件验收

- 屏幕 PCB 不弯曲，可视区域无遮挡。
- 摄像头画面四角无外壳遮挡或明显暗角。
- 两个 USB-C 插头均可完全插入，不顶住侧壁。
- BOOT/RESET 不粘滞、不会被外壳持续压住。
- 扬声器正常音量下无明显壳体共振杂音。
- 麦克风不会主要拾取壳体振动或扬声器直漏声。
- 线材不被后盖、定位舌或螺柱夹住。
- 后盖贴合且四角无翘起，设备能稳定放在桌面。

## 已知限制

当前模型是依据用户提供的模块外包络尺寸和比例照片生成的首版参数化模型。自动验证只能证明 CAD 实体有效、STL 封闭且尺寸/体积正常，不能替代实物试装。特别是 USB-C、BOOT/RESET、屏幕可视区域偏移和实际连接器突出高度，必须以试配片和实物反馈为准。
