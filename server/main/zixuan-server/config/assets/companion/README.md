# Companion cue assets

These four short WAV files are original synthetic sound effects generated for this project by OpenAI Codex on 2026-07-28. They were created from mathematical waveforms and deterministic noise by `generate_assets.py`; no third-party recording, sample, voice, or copyrighted source material was used.

The files are dedicated to the public domain under CC0 1.0. Commercial use, modification, redistribution, and inclusion in shipped hardware or paid software are permitted without attribution.

`laugh.wav` uses three rising voiced pulses. `sigh.wav` uses descending filtered noise. `hesitate.wav` uses a quiet two-part hum. `breathe.wav` uses a soft noise envelope. The generated files have not been modified after generation.
