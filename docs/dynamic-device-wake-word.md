# 按设备动态唤醒词

设备详情页支持为每台设备配置一个唤醒词。输入范围是二到八个中文汉字。保存后，后台生成 Multinet 资源，等待设备在线，下发资源并触发一次重启。

只有 ESP32-S3、assets 分区不少于 8 MiB、动态唤醒词布局版本为 2、槽位大小为 3 MiB 的设备会开放配置。布局版本为 1 的旧设备继续使用固件中的固定唤醒词，需要同时升级固件和工厂 assets 镜像后才能使用。

状态达到 ACTIVE 才表示设备已经上报并确认新词生效。资源生成或下载完成不等于生效。更新失败时，设备继续使用原有活动槽和原有唤醒词。重试沿用当前目标版本和已生成候选资源，不重复增加版本。

工厂 assets 镜像在分区尾部保留两个 3 MiB 槽。默认唤醒资源写入槽 A，槽 B 保持擦除。设备始终写入非活动槽，完成长度、SHA-256、容器、索引和 Multinet 初始化校验后才切换活动槽。

Python 对话服务只接收设备已确认生效的 active word。desired word 不会进入在线连接配置。全局默认唤醒词仍然保留，各设备连接使用自己的配置副本。

发布前需要在真实布局 2 设备上确认能力报告为 supported=true、layout_version=2、slot_size=3145728。还要验证断网、错误哈希、无效索引、Multinet 初始化失败和切槽前断电都不会破坏旧唤醒词。
