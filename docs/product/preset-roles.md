# 预设陪伴角色（草案）

新用户登录后从预设角色里选一个开始聊天，之后可以在角色列表里“添加角色”。这份文档记录预设角色现在的设定。

**这是草案。** 角色的定位、名字、语气和音色是产品决定，下面的内容是为了让流程能跑通而写的第一版，需要确认或改写后再对外。

最早的三个角色（紫萱、阿澈、小满）是想覆盖三种来聊天的原因：想被安慰、想把事情想清楚、想找人说说今天。后面七个按使用场景补充：生活伴侣、情感陪伴、情侣对话（女友、男友）、老年陪伴、生活助理、英语学习，来源和形象见 `docs/product/role-candidates.md`。这个划分没有用户数据支持，内测时应该看每个角色的选择比例和留存再调整。

糯糯和哔哔是 2026-11-28 加的两个 Mowa Bot 角色模板，方便用户在“添加一个角色”里一键建一个 Mowa Bot 角色。它们没有画好的 2D 图：网页端 `lib/roles.ts` 的 `MOWA_TEMPLATES` 让同名的角色默认用对应的 Mowa Bot 角色，用户可以在角色设置里换别的 Mowa Bot 角色、画风或小动物。模板在服务启动时按 `CompanionPresetRoles.ALL` 补齐，不需要迁移；豆包语音没启用的部署用默认音色。

## 每个角色都遵守的约定

写在每个角色的提示词里：

- 陪伴的是成年用户，关系模式是朋友，不擅自扩展恋爱剧情。
- 不冒充真人，不制造依赖，尊重用户的自主选择、现实关系和个人边界。
- 用简短的口语交流。
- 使用结构化情绪协议，不把叹气、笑声或括号里的动作描写写进正文。

平台的内容安全守则（`docs/content-safety.md`）对所有角色生效，并且优先于角色设定。

## 在哪里改

- 人设、介绍和音色定义在 `manager-api` 的 `zixuan/modules/companion/init/CompanionPresetRoles.java`。
- 服务启动时，缺少的角色模板会按这份定义创建，写入 `ai_agent_template`（`agent_code` 分别是 `zixuan-companion`、`ache-companion`、`xiaoman-companion`、`sunian-companion`、`niangao-companion`、`wanzhou-companion`、`jiangyu-companion`、`xiaole-companion`、`qiubai-companion`、`maple-companion`）。
- **已经存在的模板不会被覆盖。** 模板建好之后，在管理台的角色模板里改提示词和音色即可；改代码里的定义只影响还没有这个模板的环境。
- 用户已经创建的角色是从模板复制出来的，改模板不会影响它们。
- 一句话介绍目前只在代码里，管理台里改不了。
- 预设音色只在默认语音合成是 EdgeTTS、并且这个音色存在时使用；部署换了别的语音合成时，所有预设角色都沿用默认模板的音色，需要在管理台里分别指定。

## 网页端

- 新账号：登录后先选一个角色，每个角色显示名字和一句话介绍。
- 已有角色的用户：点左上角的当前角色打开角色列表，底部有“添加角色”，已经有的角色显示“已添加”，不能重复添加。添加完自动切到新角色。
- 紫萱、阿澈、小满各有一个玩偶形象，后面七个是日系 2D 形象，都按角色名字对应，见 `docs/product/companion-web-design.md`。
- 每个角色的对话记录各自分开。第一次切到新角色时，角色会先打招呼（见 `docs/conversation-opening.md`）。
- 每个用户最多能有几个角色由套餐决定，基础套餐是 3 个。

## 还没做的

- 头像不保存在服务端，网页端按角色名字对应到图片。管理台里新加的预设角色没有头像，用名字的第一个字代替。
- 没有试听音色。
- 用户现在可以在网页端改自己角色的名字、性格、声音、提示词和形象，也可以删除角色、从空白新建，见 `docs/product/companion-web-design.md`。预设只是起点。
- 角色的介绍和排序不能在管理台里配置。

## 恋人模式的角色

苏念（`sunian-companion`）和江屿（`jiangyu-companion`）的关系模式是 `lover`，其余预设仍是 `friend`。

- 后端已有 `relation_mode` 字段（`friend` / `lover`，管理台显示为“治愈型朋友”和“治愈型恋人”），连接配置里也会带上这个值。`CompanionPresetRoles.relationModeOf` 决定从哪个预设模板创建的角色是 `lover`，`CompanionProfileServiceImpl` 创建角色时使用它，`/companion/templates` 也按它返回。
- 目前运行时只是透传这个值，行为的约束写在提示词里：只面向成年人，用户表明未满 18 岁时改成普通朋友，不写性内容，不吃醋，不阻止用户离开。平台守则（`docs/content-safety.md`）仍然优先。
- 用户可以在管理台或网页端把关系模式改回 `friend`，提示词不会跟着变，改了之后建议同时检查提示词。
- 形象是日系 2D 立绘，不是 3D 玩偶，也没有定制的 Live2D 模型，网页端的 Live2D 模式暂时用示例模型 Hiyori。图片在 `server/main/companion-web/public/roles/sunian*.webp`，原图和做法见 `docs/product/role-candidates.md`。

## 年糕（生活伴侣）

2026-11 新增，来自 `docs/product/role-candidates.md`。形象是银白长卷发、灰色虎斑猫耳和尾巴的猫耳少女（设定稿「墨婉 / MOWA」），有四套装扮，用户在角色设置里换（记在浏览器里）：

| 装扮 | key | 图片 | 来源 |
|---|---|---|---|
| 主播装（默认） | `host` | `public/roles/niangao-host*.webp` | 以设定稿「墨婉 / MOWA」v2 第 3 轮主播装为参考重新生成：右手在肩旁轻轻挥手、左手扶耳麦，再出闭眼、张嘴 |
| 大小姐 | `lady` | `niangao-lady*.webp` | 以第 2 轮 V1 原装半身图和大小姐版三视图为参考：右手手背轻贴脸颊、左手托肘，闭嘴的笑，再出闭眼、张嘴 |
| 银发卫衣 | `silver` | `niangao-silver*.webp` | 照「黑银发色初版」三视图和海报，生成同样双手猫爪的半身，再出闭眼、张嘴 |
| Q 版 | `chibi` | `niangao-chibi*.webp` | 照「Q 版设定」A、C 两张生成，做法同上 |

- 最早四套都是“双手猫爪扒窗沿”的姿势，那是给视频主持人探头用的。放进网页后显得幼、没气质，2026-11-26 把主播装和大小姐换成了上面的姿势（候选和选择见设计目录的 `姿势候选-对照.jpg`）。银发卫衣和 Q 版还是猫爪。
- 新装扮的原图、提示词和生成记录在设计目录 `06-角色设定/网页端-年糕装扮/`（不进仓库）。闭眼、张嘴的图先用 `v2-重设计/工具/composite.py` 对齐到底图、只把眼睛和嘴贴回去，再用 Vision 抠图，导出时只留真正变了的那一块做透明补丁，和 `scripts/role-frames.py` 一样。
- **主播装是 Live2D 模型**（`public/models/niangao-host/`，约 12 MB，gzip 后约 3.8 MB），会转头、歪头、眨眼、对口型，头发有物理摆动；其他装扮还是 2D 图。头像、选角色和静态图仍用 `niangao-host*.webp`。2026-11-26 做的，步骤：
  1. 把精致的主播装立绘（白底、方形）交给 [See-through](https://github.com/shitagaki-lab/see-through)（Hugging Face 上跑，要登录令牌）拆成 21 层。它不认识猫耳：一截尾巴被标成了耳朵，另一只猫耳和腰带以下的裙子没进任何一层，这几块直接从原图取。
  2. 闭眼、张嘴各用图生图出一张，对齐原图后只取变化的那块。
  3. 图层改成 [live2d-halfbody-skill](https://github.com/bellisji233/live2d-halfbody-skill) 的 rigkit 认的名字（左右要对调：See-through 的 `l` 是角色自己的左边），用它的 `estimate`、`prepare`、`build` 生成 `.moc3`，再用它的 `physics()` 导出头发物理。没走它“重绘立绘”那一步：它的绘制规则会把肩前长发、链子、柔和阴影都去掉，精致的形象做出来很糙。
  4. 压小：头发晶格 32→64 px，脸和头发的变形网格起始格 12→32 px、误差上限 0.35→1.5 px（网页里角色最大约 600 px，看不出差别），贴图 4096 PNG→2048 无损 WebP。原始 40 MB 降到 12 MB。
  rigkit 本地改过一处：只有一束刘海、没有侧发时它会报错。脚本、图层、中间文件和测试页在设计目录 `06-角色设定/网页端-年糕装扮/Live2D试做/`。
  已知问题：扶耳麦的手和挥手的手跟着身体走，转头时麦杆会稍微离开手指；表情（笑眼、O 型嘴、换眉）没做。上线前要确认 Live2D Cubism Core 的授权档位。
- 2026-11-28 去掉了原来的橘猫卫衣（橘发、橙色卫衣），提示词开头的外貌改成银发虎斑猫娘，迁移 `202611281000` 同步了还保留默认开头的模板和角色。以前选过橘猫卫衣的浏览器会回到主播装。人设其他部分（舒适之神、甜妹室友）不变。
- 没有定制的 Live2D 模型，`lib/roles.ts` 里先指向示例模型 Mao 占位。
- 人设比原稿更具体：三分糖少冰加波波的“续命水”、从不给十分的舒服分、被说胖先炸毛、嫌弃只用在小事上、不说“只有我懂你”。平台守则和 `SHARED_RULES` 照常适用。
