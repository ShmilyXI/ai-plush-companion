# 可视化屏幕编排器设计

**日期**：2026-10-19  
**目标设备**：ESP-VoCat  
**状态**：待用户审阅

## 背景

ESP-VoCat 使用 1.85 英寸圆形 ST77916 QSPI 屏，逻辑分辨率为 360×360，触摸控制器为 CST816S。当前固件通过 EmoteDisplay 加载固定资源分区中的 EAF 表情动画，并按待机、聆听、说话等状态切换表情。设备已经具备 MQTT、设备 MCP 工具和资源分区下载能力，但还没有一个可以由网页编排屏幕内容的统一模型。

目标是增加一个可视化屏幕编排器，让管理员可以为不同设备定义画布、图层、状态内容、动画和触摸热区，并在网页上发布到设备。设计必须支持未来分辨率、比例和屏幕形状不同的设备。

## 用户能力

管理员可以创建和编辑多个屏幕场景。每个场景可以绑定一个显示模式：

- 静态图模式，显示单张或一组图片。
- 对话模式，显示状态、字幕和基础反馈。
- 带表情的对话模式，在对话状态上叠加 EAF 表情动画。
- 纯文字对话模式，只显示文字和状态。
- 自定义内容展示模式，完全由场景图层控制。

管理员可以设置画布宽度、高度、形状和安全边距。编辑器按设备能力实时预览圆形裁切、图层位置和触摸区域。

管理员可以添加图片或动画、文字、状态绑定图层和触摸热区。图层至少支持位置、尺寸、层级、透明度、显示条件和资源引用。显示条件可以绑定设备状态，例如 idle、listening、thinking、speaking、error 和当前模式。

触摸热区支持矩形和圆形区域。快捷动作从设备上报的 MCP 工具和状态动作中选择，自动生成绑定。高级动作允许填写 MQTT topic、QoS 和受限 JSON payload 模板，模板只能使用设备 ID、当前模式、当前状态和触摸坐标等白名单变量，不允许上传或执行代码。网页在发布前展示最终 payload 预览。

设备用户可以长按屏幕 800 毫秒打开模式面板。面板显示五种模式和当前场景，点击后立即切换。短按和普通触摸事件继续交给当前场景热区。

## 场景模型

场景使用版本化 JSON 表示，核心字段如下：

```json
{
  "schema_version": 1,
  "scene_id": "scene-id",
  "version": 3,
  "mode": "emotion_chat",
  "canvas": {
    "width": 360,
    "height": 360,
    "shape": "circle",
    "safe_inset": 24
  },
  "layers": [
    {
      "id": "layer-id",
      "type": "image",
      "resource": "assets/idle.png",
      "x": 0,
      "y": 0,
      "width": 360,
      "height": 360,
      "opacity": 1,
      "visible_when": {"state": "idle"}
    }
  ],
  "touch_regions": [
    {
      "id": "touch-id",
      "shape": "rect",
      "x": 24,
      "y": 24,
      "width": 96,
      "height": 72,
      "action": {
        "kind": "device_tool",
        "name": "self.audio_speaker.set_volume",
        "arguments": {"volume": 80}
      }
    }
  ],
  "resources": {
    "manifest_sha256": "..."
  }
}
```

设备能力报告包含物理或逻辑宽高、形状、触摸坐标范围、支持模式、支持资源类型和最大资源包大小。网页使用这些能力生成预览约束。设备只解析白名单字段和动作类型。

## 资源与发布

网页发布时把场景 JSON、图片、EAF 动画和字体引用整理成带版本号的资源包。服务端保存草稿和已发布版本，设备只下载已绑定的已发布版本。

设备下载资源包时校验长度、SHA-256、场景 schema、资源索引和容量限制。资源写入备用区域，全部校验通过后再切换活动版本。下载失败、解析失败、容量超限或切换前掉电时继续使用旧版本。

ESP-VoCat 现有资源分区由 `CONFIG_FLASH_EXPRESSION_ASSETS=y` 生成 `expression_assets.bin`，包含 360×360 的 `.eaf` 表情资源和布局文件。静态图与自定义场景需要扩展资源索引和渲染运行时，不能把网页上传的 PNG 直接当成 EAF 文件。

## 运行时

固件增加场景运行时，负责解析活动场景、绘制图层、按设备状态更新可见内容、处理文字和图片资源，以及把触摸坐标转换成场景坐标。圆形屏幕使用画布遮罩裁掉边缘区域。不同屏幕比例通过场景画布到设备画布的缩放和对齐策略适配。

长按模式面板由固件内置，不依赖远程场景。模式切换写入设备设置并立即刷新显示。模式面板无法加载时继续使用当前场景。

设备保留现有 EmoteDisplay 作为表情动画渲染路径。带表情的对话模式优先引用 EAF 资源；静态图片和自定义图层使用统一资源读取接口。

## 服务端与网页

管理端增加屏幕编排页面，包含设备选择、画布尺寸和形状设置、图层树、属性编辑器、状态时间轴、触摸热区编辑器、资源上传、MQTT payload 预览和发布历史。

服务端增加场景草稿、发布版本、资源清单和设备绑定关系。场景发布接口必须检查设备能力和资源包限制。运行时按设备隔离场景，不允许一台设备的场景或动作出现在另一台设备。

服务端复用现有设备 MQTT、Manager API 和资源下载边界。高级 MQTT 动作经过 schema 校验和设备绑定校验，密钥不返回浏览器。

## 验证

网页编辑器验证画布比例、圆形裁切、图层排序、状态条件、触摸热区拖拽、快捷工具选择、MQTT payload 预览和发布回滚。

服务端验证场景 schema、资源包哈希、版本不可覆盖、按设备隔离、能力不匹配拒绝、失败下载保留旧版本和高级动作白名单。

固件验证 360×360 ESP-VoCat、不同宽高比画布、静态图、文字、EAF 动画、状态切换、长按模式面板、触摸热区、下载失败、断电切换和旧版本回退。普通对话链路必须在场景资源失败时继续可用。
