# ADR 0001 统一文字与实时语音会话

## 状态

已接受

## 背景

消费者 App 需要同时支持文字聊天、单轮语音输入和实时语音通话。用户希望在不同交互方式之间继续同一段关系，而不是维护两套互相断开的历史和记忆。

## 决策

文字聊天、单轮语音输入和实时语音通话都属于同一个用户与陪伴角色之间的对话。进入实时语音通话时沿用当前对话上下文；暂停只停止收音，结束才关闭实时会话并生成可回看的文字记录。用户可以在同一对话中从文字切换到通话，再回到文字。

角色身份在一段对话中保持不变。切换角色从新对话开始，避免一段上下文同时混入不同的系统提示词、音色和记忆空间。

后台预设角色只用于创建用户副本。用户修改副本不会改变后台预设，也不会悄悄改写已经存在的对话。

实时语音通话采用全屏电话式界面。进入通话后默认开启免提持续收音，由本地 VAD 识别说话和停顿并提交轮次；角色说话时允许用户直接打断。静音只关闭麦克风，挂断才结束实时会话，结束后回到原对话并保留文字记录。

通话支持切到其他 App 或锁屏后继续。系统通知提供返回通话和结束通话入口；系统限制、麦克风权限变化或用户主动静音时，通话暂停但不丢失当前对话。

单轮回复音频也支持后台和锁屏播放。通知提供暂停、继续和停止；同一时间只允许一条回复音频播放，系统音频中断后不重新发送对话。

语音长期只保存文字转写，不保存用户原始录音或整段通话录音。角色回复音频按需生成并只做临时缓存，缓存可被系统清理。

实时通话使用免提连续收音和本地 VAD。检测到停顿后提交一轮；AI 播放期间继续监听，用户开始说话时立即取消当前输出并开始新一轮。通话页面保留静音、扬声器和挂断控制。

## 取舍

统一会话让历史浏览、记忆归属和断线恢复只有一套语义，也符合主流移动端语音产品的行为。代价是实时语音连接需要可靠地挂接到已有对话，并在结束时整理转写和中断状态。
