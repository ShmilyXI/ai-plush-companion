# ADR 0002 App 内嵌设备配网网页

## 状态

已接受

## 背景

实体设备会进入临时 Wi-Fi 热点，并提供现有的固定配置网页。网页提交 Wi-Fi 后跳转到 `/done.html`，完成页请求 `/exit` 让设备退出配网模式。用户还需要用六位激活码把已联网设备绑定到账号和陪伴角色。

## 决策

消费者 App 在自己的配网流程中内嵌现有配置网页。App 监听网页导航到 `/done.html` 作为配网成功信号，关闭网页后等待设备重新连接服务端，再让用户输入六位激活码并选择角色，调用现有设备绑定接口完成绑定。

App 不把激活码或云端账号凭据传入设备网页，也不依赖设备内部的 `OnExitRequested` 回调作为客户端事件。Android 或 iOS 不允许自动切换 Wi-Fi 时，流程转为系统设置引导，回到 App 后继续状态检查。

## 取舍

复用现有网页可以保持硬件协议和固件边界稳定，App 只负责承载网页、识别完成页和编排绑定步骤。代价是需要处理 WebView 导航拦截、热点断开、系统 Wi-Fi 设置往返和设备重新上线的等待状态。
