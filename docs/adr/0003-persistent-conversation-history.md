# ADR 0003 持久化消费者会话历史

## 状态

已接受

## 背景

消费者 App 需要在聊天页左侧提供会话列表，让用户选择历史对话、继续对话或新开对话。现有公共会话历史仅按已知会话 ID 查询，Redis 临时保留，无法支持长期列表。

## 决策

为消费者会话建立用户可见的持久化索引和历史存储。每条会话归属于一个用户和一个陪伴角色，侧栏显示角色、标题和最近活动时间，支持新建、继续、重命名和删除。会话删除是明确的不可逆操作，删除后不再出现在用户历史中。

删除会话不删除该角色的长期记忆。记忆删除和清空只能在角色记忆管理中单独执行。

## 取舍

持久化让跨设备继续对话和历史侧栏有稳定语义，也不再依赖短期运行时 token 的生命周期。代价是需要设计会话索引、分页、删除和与实时运行时写入的一致性，并处理已有 Redis 历史的迁移或过期边界。
