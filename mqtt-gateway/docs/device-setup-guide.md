## 配置新设备

### 方法 1: 通过管理控制台（推荐）

1. **打开管理控制台**
   ```bash
   open http://localhost:8001
   ```

2. **登录系统**
   - 使用管理员账号登录

3. **进入设备管理**
   - 点击左侧菜单「设备管理」
   - 查看当前已注册设备列表

4. **添加新设备**
   - 点击「添加设备」按钮
   - 输入设备信息（MAC 地址会自动获取）
   - 设置设备别名

5. **配置 Wi-Fi**
   - 设备首次启动时会进入配网模式
   - 设备会创建一个 Wi-Fi 热点（通常以 "ESP32" 或板子名称开头）
   - 使用手机或电脑连接该热点
   - 在浏览器中访问配网页面（通常是 192.168.4.1）
   - 选择你的 Wi-Fi 网络并输入密码

### 方法 2: 查看已连接设备

当前连接的设备端口: `/dev/cu.usbmodem101`

**检查设备状态**:
```bash
# 查看串口输出
screen /dev/cu.usbmodem101 115200
```

**设备运行状态**:
- ✅ 设备已通电
- ✅ 固件正常运行
- ⏳ 内存状态正常（约 48-51 KB 可用）
- ⚠️  未看到网络连接日志

### 方法 3: 通过串口配置（高级）

如果设备支持串口配置命令，可以通过以下方式配置：

```bash
# 连接到设备串口
screen /dev/cu.usbmodem101 115200

# 在串口终端中输入配置命令（具体命令取决于固件版本）
# 例如:
# wifi_config <SSID> <PASSWORD>
# server_config <MQTT_HOST> <MQTT_PORT>
```

```yaml

```

### Wi-Fi 配置

设备需要连接到与服务器相同的局域网：
- 网络地址段: 192.168.0.x
- 确保设备可以访问服务器 IP: 192.168.0.108

## 故障排查

### 设备无法连接 Wi-Fi

1. **检查 Wi-Fi 信号**
   - 确保设备在 Wi-Fi 覆盖范围内
   - 检查 Wi-Fi 密码是否正确

2. **查看串口日志**
   ```bash
   screen /dev/cu.usbmodem101 115200
   ```
   查找 Wi-Fi 连接相关的错误信息

3. **重置设备**
   - 按下设备上的复位按钮
   - 或通过串口发送重启命令

### 设备已连接但无法通信

1. **检查 MQTT 网关**
   ```bash
   lsof -i :1883
   ```
   确保 MQTT 网关正在运行

2. **检查防火墙**
   - 确保端口 1883、8000、8003 未被防火墙阻止

3. **查看设备注册状态**
   - 在管理控制台查看设备是否已注册
   - 检查设备 MAC 地址是否正确

### 设备日志只显示内存信息

这通常表示：
- ✅ 固件正常运行
- ⚠️  可能未配置 Wi-Fi
- ⚠️  或 Wi-Fi 连接失败

**解决方法**:
1. 进入设备的配网模式
2. 通过 Wi-Fi 热点配置网络
3. 或通过串口手动配置
